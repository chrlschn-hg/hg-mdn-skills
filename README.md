# Hg Modern .NET ("modern dotnet" or "MDN") Skills

A set of skills for scaffolding and building modern .NET backends.

## Rationale

Many of Hg's portfolio companies are .NET or C# as this is a stable, performant backend to build on.

However, many teams:

- May be on older versions and lack the internal expertise to build new, modern .NET setups
- May not be keeping up with best practices and tooling in the .NET ecosystem
- May need a foundational baseline to quickly experiment with and get up to speed

## Purpose

Therefore, this set of skills is designed to help teams quickly onboard with practices that:

- Promote modern usage of the language features
- Promote modern usage of tooling to improve the developer experience (DX)
- Promote fast developer inner loops by scaffolding several key technologies
- Scaffold modern AI use cases with Microsoft Agent Framework, OpenTelemetry for observability, MCP for building server backends
